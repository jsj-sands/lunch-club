글자 확대 / 섹션 구분 개선본

[적용 방법]
1. ZIP 파일을 압축 해제합니다.
2. GitHub의 jsj-sands/lunch-club 저장소로 이동합니다.
3. Add file > Upload files에서 다음 3개 파일을 교체합니다.
   - index.html
   - styles.css
   - app.js
4. Commit changes를 누릅니다.
5. 사이트 반영 후 점심판을 새로고침합니다.

위 3개만 기존 파일과 같은 위치에 올리세요.
새 하위 폴더에 넣거나 기존 다른 파일을 삭제하지 마세요.
기존 assets 폴더와 core.js 등은 그대로 유지합니다.
Google Apps Script 수정 / 재배포는 필요 없습니다.
직원 이메일, Slack 알림, 팀 키, 공유 주소는 바꾸지 않습니다.

[변경 내용]
- 본문 18px, 주요 안내 16px, 직원 이름 18px.
- 섹션 제목 26~30px (아주 작은 화면은 24px).
- 점심 현황 / 구내식당 식단 / 과천 맛집 / 선택 결과를 독립된 영역으로 구분.
- 영역별 색상, 제목 배경, 굵은 경계선, 여백 추가.
- 상단에 고정되는 4개 바로가기 버튼.
- 휴대폰에서 버튼과 카드를 재배치하고 초대 팝업 글자도 확대.
- 런치타임 식단 이미지 직접 업로드 제거 상태 유지.
