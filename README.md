# SANDS Lunch Club · 오늘 점심

김윤철, 오성은, 장윤석, 서지우, 천진기, 최민준, 조현주, 손주리, 윤현수, 조성준 총 10명의 식단 확인·참석 선택·식당 투표를 위한 GitHub Pages용 웹앱입니다.

압축을 풀고 `index.html`을 열면 화면을 확인할 수 있습니다. **이번 버전은 GitHub 파일과 기존 Google 공유 서버를 모두 업데이트해야 합니다.** 자세한 복사·붙여넣기 안내와 최신 서버 코드는 `setup.html`에 있습니다.

## 이번 수정 · 참석 선택과 따로 먹기

### 눈에 보이는 내 점심 선택

현황 위에 **오늘 점심, 어떻게 할까요?** 패널을 넣었습니다. **나는 → 내 이름**을 고른 뒤 큰 버튼 **함께 먹기 · 따로 먹기 · 안 먹기**를 누릅니다. 이름을 눌러야만 선택창을 찾을 수 있었던 기존 경로도 보조 기능으로 남아 있습니다.

| 현황 | 들어가는 사람 |
| --- | --- |
| 함께 점심 · 초록색 | 직접 **함께 먹기**를 선택한 사람 |
| 대표님과 점심 | 그날의 기본 대표님 일정이 있거나 직접 대표님과 먹기를 선택한 사람 |
| 오늘 안 먹음 | 직접 **안 먹기**를 선택한 사람 |
| 미선택 | 아직 응답하지 않았거나 선택·개인 대표님 일정을 취소한 사람 |
| 따로 먹는 점심 | 동료와 따로 먹거나 개별 식사를 선택한 사람. 모임 카드를 별도로 표시 |

- 대표님 기본 일정 외에는 **미선택**으로 시작합니다. 주말도 같습니다. 날짜가 바뀔 때 전날의 선택이 자동으로 이어지지 않습니다.
- 직접 함께 먹기를 선택한 사람만 함께 먹는 인원·식당 투표 집계에 포함됩니다. 점심 확정도 함께 먹는 사람이 할 수 있습니다.
- **안 먹기** 사유에 **연차·반차·외근·출장**을 하나의 항목으로 추가했습니다. 사유는 선택사항이며 기존 사유와 직접 입력도 사용할 수 있습니다.
- **선택 취소 · 미선택으로**를 누르면 내 선택을 해제할 수 있습니다.
- 한 번에 하루만 봅니다. **← / →**, 날짜 입력, **오늘** 버튼을 유지했습니다. 선택과 모임은 화면에 표시한 날짜에 저장됩니다.
- 네 현황 그룹은 PC에서 2×2, 모바일에서 한 열로 배치합니다. 팀명은 한 번만 표시하고 이름은 줄바꿈합니다. 팀명 가나다순 → 이름 가나다순으로 정렬합니다.

### 대표님 점심 취소

- 내 상태가 대표님과 점심이면 선택 패널에 **내 대표님 점심 취소** 버튼이 나타납니다. 누르면 **나만 미선택**으로 이동합니다. 이후 함께 먹기·따로 먹기·안 먹기를 직접 고릅니다.
- 그날의 전체 일정이 취소되었으면 별도의 **오늘 대표님 점심 전체 취소** 체크를 사용합니다. 자동 기본 일정에 해당하는 사람들이 미선택으로 이동합니다. 개인이 직접 선택한 참석·불참·대표님 일정·따로 먹기는 유지됩니다.
- 전체 취소를 해제하면 자동 기본 일정이 돌아옵니다. 개인적으로 취소했던 상태는 유지됩니다. 개인 일정 복원은 선택 패널의 **내 기본 대표님 일정 복원** 또는 내 이름의 상세 선택창에서 할 수 있습니다.
- 취소 후 자동으로 함께 먹는 인원에 들어가지 않습니다.

### 둘이 따로 먹는 모임

예를 들어 손주리와 윤현수가 따로 먹을 때:

1. 손주리가 본인 이름을 선택합니다.
2. **따로 먹기 → 윤현수 선택 → 따로 먹기 초대하기**를 누릅니다.
3. 손주리는 따로 먹는 인원으로 이동하고, 모임에는 **윤현수님 초대 중**이 표시됩니다. 윤현수의 기존 상태는 아직 유지됩니다.
4. 윤현수가 본인 이름을 선택하면 선택 패널 아래에 초대가 보입니다. **수락하고 따로 먹기**를 누르면 두 사람을 한 모임으로 표시합니다.
5. 두 사람은 함께 점심 인원과 공통 식당 투표 집계에서 빠집니다. 그날의 다른 동료들은 이 모임을 볼 수 있습니다.

초대는 이 점심판 안에 표시됩니다. 동료의 기기에서도 보려면 같은 팀 공유 연결을 사용해야 합니다. 선택 결과와 초대는 화면이 열려 있는 동안 약 30초마다 확인합니다.

- 혼자 먹는 경우에는 **동료 지정 없이 따로 먹기**를 사용합니다.
- 대기 중인 초대를 포함해 한 사람은 한 모임에만 속합니다. 현재는 두 사람을 묶는 기능입니다.
- 대기 중 초대는 보낸 사람이 취소하거나 받은 사람이 거절할 수 있습니다. 초대한 사람은 따로 먹기로 남습니다.
- 수락한 모임에서 **모임 나가기 · 미선택으로**를 누르면 본인만 미선택이 되고, 상대는 개별 따로 먹기로 남습니다.
- 참석 상태를 새로 고르면 본인이 속한 초대·모임도 정리됩니다. 다른 사람의 개인 선택은 유지됩니다.

## 기존 점심판 교체 순서

### 1. GitHub 파일을 교체합니다

1. `SANDS_Lunch_Club_GitHub.zip`을 다운로드하고 압축을 풉니다.
2. 기존 GitHub **lunch-club** 저장소에서 **Add file → Upload files**를 누릅니다.
3. 압축을 푼 폴더 **안의 파일과 하위 폴더를 모두** 끌어놓습니다. 새 파일 `restaurant-guide.js`도 포함합니다. `index.html`이 저장소 첫 화면에 있는 위치를 유지합니다.
4. 현재 Pages에 사용하는 브랜치에 **Commit changes**로 저장합니다.
5. Pages 업데이트가 끝나면 아래의 공유 서버도 갱신합니다.

### 2. 기존 Google 공유 서버를 업데이트합니다

**이미 10명 명단을 서버에 적용한 경우에도 이번에는 필요합니다.** 새 참석 상태와 초대 저장 기능이 서버에도 추가되었습니다.

1. **평소 팀 공유에 연결해 쓰던 브라우저**에서 [업데이트 안내](https://jsj-sands.github.io/lunch-club/setup.html#update)를 엽니다.
2. 강력 새로고침합니다. Windows: **Ctrl+Shift+R**, Mac: **⌘+Shift+R**. 맨 위 제목이 **이번 수정본 · 참석 선택과 따로 먹기**인지 확인합니다.
3. **공유 서버 코드 전체 복사**를 누릅니다. 이 브라우저에 저장된 기존 팀 키가 코드에 들어갑니다. 다른 브라우저라면 ‘다른 브라우저에서 설정했거나 기존 팀 키가 있어요’에 기존 키를 입력한 뒤 복사합니다.
4. Google Apps Script의 **기존 SANDS 점심판 프로젝트**를 엽니다. `Code.gs` 전체를 복사한 코드로 바꾸고 저장합니다. 이미 공유·이미지 연결을 완료했다면 초기 실행은 필요하지 않습니다.
5. **배포 → 배포 관리 → 현재 웹 앱 선택 → 수정(연필) → 버전: 새 버전 → 배포**로 갱신합니다.
6. 점심판을 새로고침합니다. 서버 업데이트 안내가 사라지고 **팀 공유 연결됨**이 표시되면 새 선택을 사용할 수 있습니다.
7. 한 사람이 함께 먹기를 선택하고 다른 기기에 반영되는지, 따로 먹기 초대가 상대 화면에 보이는지 확인합니다.

같은 Apps Script 프로젝트·팀 키·기존 배포를 사용하면 공유 주소와 초대 링크, 기존 개인 선택·설정·공용 이미지를 이어서 쓸 수 있습니다. ZIP의 `backend/Code.gs`는 팀 키가 비어 있는 원본이므로 **setup.html 코드 복사 버튼**으로 만든 코드를 붙여넣으세요.

예전 화면에서 자동으로 함께 먹는 것으로 보이던 사람은 새 버전에서 **미선택**입니다. 예전에 직접 선택한 참석·불참과 식당 선택은 유지됩니다. 미선택인 사람의 예전 식당 선택은 저장해 두고, 직접 함께 먹기를 선택했을 때만 다시 집계합니다.

아직 공유 연결을 만들지 않았다면 `setup.html`의 **처음 설치** 순서를 따르면 됩니다.

## 공유와 파일 구성

기존 Google Apps Script 연결을 사용합니다. 선택·초대는 Script Properties, 식단 이미지는 초기 실행 때 만든 전용 비공개 Drive 폴더에 보관합니다. 주기적인 조회는 이미지 정보만 전송하고 파일은 필요할 때 가져옵니다. 서버 잠금과 변경별 확인 응답을 통해 동시 변경을 처리하며, 저장 확인을 받아야 성공을 표시합니다.

팀 키가 맞는 요청만 처리하는 소규모 팀 공유판입니다. 초대 링크를 가진 사람은 멤버 이름을 선택해 기록을 수정할 수 있습니다. 실제 팀 키·팀 키를 넣은 서버 코드·초대 링크는 공개 저장소에 올리지 마세요. 배포용 기본 소스에는 실제 팀 키가 없습니다.

공유 기록과 전용 이미지는 최근 90일 기준으로 정리합니다. 로컬 점심 기록은 최근 120일을 보관합니다. 서로 다른 기기에서 자동으로 같은 결과를 보려면 같은 공유 연결을 사용해야 합니다.

| 파일 | 역할 |
| --- | --- |
| index.html / styles.css | PC·모바일 점심판 화면 |
| app.js | 참석 선택·모임·맛집·공유 화면과 이벤트 |
| core.js | 날짜·멤버·참석·초대·투표 규칙 |
| restaurant-guide.js | 네이버에서 확인한 과천 음식점 33곳 |
| menu-source.js | 공개 메가존 식단 조회와 응답 검증 |
| setup.html | 설치·업데이트 안내와 최신 서버 코드 복사 |
| backend/Code.gs | core.js와 서버 코드를 합친 Apps Script 원본 |
| backend/server.js / setup.template.html | 서버·설정 안내 원본 |
| tests/ / CHECKS.txt | 검증 코드, 결과와 범위 |

빌드나 외부 패키지 설치는 필요 없습니다. Node.js가 있으면 `node --test tests/*.test.cjs`로 기능 검증을 실행할 수 있습니다. 실제 GitHub·Google 배포는 사용자의 계정에서 위 순서로 진행합니다.
