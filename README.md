# SANDS Lunch Club · 오늘 점심

김윤철, 오성은, 장윤석, 서지우, 천진기, 최민준, 조현주, 손주리, 윤현수, 조성준 총 10명의 식단 확인·참석 확인·식당 선택을 위한 GitHub Pages용 웹앱입니다.

압축을 풀고 `index.html`을 열면 수정된 화면을 확인할 수 있습니다. 설치 및 기존 서버 업데이트 순서는 **`setup.html`**에 있습니다.

## 이번 수정 · 간단한 일일 현황

화면은 **오늘 점심 현황 → 오늘은 어디로 갈까요?** 순서입니다. 기존 사람 카드와 주간 표를 한 곳으로 합쳤습니다.

- **함께 점심 / 대표님과 점심 / 오늘 안 먹음** 세 그룹으로 이름과 인원수를 보여 줍니다. 한 사람은 한 그룹에만 표시됩니다.
- 한 번에 선택한 하루만 봅니다. **← / →**를 누르면 하루씩 이동하고, **오늘** 버튼을 누르면 오늘로 돌아옵니다. 날짜 입력에서 원하는 날로 바로 이동할 수도 있습니다.
- 내일·모레를 보고 있을 때는 표시 인원·본인 참석 변경·대표님 점심 취소가 모두 선택한 날짜 기준으로 적용됩니다. 다른 날짜에는 영향을 주지 않습니다.
- PC에서는 세 그룹이 나란히 보이고, 모바일에서는 한 열로 배치됩니다. 팀명은 한 번만 표시하고 이름은 짧은 버튼으로 모아 가로 스크롤 없이 확인합니다.
- 각 그룹 안에서 **팀명 가나다순 → 이름 가나다순**으로 정렬합니다. 내 이름 선택과 기본 일정 설정, 투표자·확정 인원·공지의 이름 순서에도 같은 기준을 적용합니다.
- 본인의 이름을 누르면 참석·불참·불참 사유를 바꿀 수 있습니다. 동료의 이름을 누르면 그날의 일정 상세를 확인합니다.
- **오늘 대표님과 점심 취소**를 체크하면 해당 날짜의 기본 대표님 점심 참석자가 함께 점심으로 이동합니다. 체크를 해제하면 기본 일정으로 돌아갑니다. 직접 정한 불참·참석·별도 대표님 일정은 유지됩니다.
- 디자인팀 서지우·천진기는 화요일, 연구기획팀 최민준은 월·목요일 등 기존 기본 일정을 유지합니다.
- 팀 공유 연결 시 변경 내용이 기존 공유 서버에 저장되고 다른 기기에서 약 30초마다 확인됩니다. 연결 전에는 이 기기에만 저장됩니다.

총 10명 명단, ‘대표님과 점심’ 표현, 메가존 오늘·주간 식단, 런치타임 채널과 공용 이미지 기능을 모두 포함합니다.

## 기존 점심판 교체 순서

### 직전 10명 수정본의 공유 서버까지 적용했다면

이번 일일 현황 화면은 기존 서버 기능을 사용합니다. **GitHub 파일만 교체하면 됩니다.**

1. `SANDS_Lunch_Club_GitHub.zip`을 압축 해제합니다.
2. GitHub의 기존 `lunch-club` 저장소 첫 화면에서 **Add file → Upload files**를 누릅니다. 압축을 푼 폴더 **안의 파일과 하위 폴더를 전부** 끌어놓고 기존 Pages에 쓰던 브랜치에 **Commit changes**로 저장합니다. `index.html`이 저장소 첫 화면에 있는 위치를 유지합니다.
3. GitHub Pages 업데이트가 끝나면 점심판에서 강력 새로고침합니다. Windows: **Ctrl+Shift+R**, Mac: **⌘+Shift+R**.
4. ‘오늘 점심 현황’에 세 그룹이 보이는지 확인합니다. 화살표로 내일·모레를 확인한 뒤 ‘오늘’으로 돌아오고, 본인 참석 변경이 다른 직원 화면에도 반영되는지 확인합니다.

### 아직 10명 명단을 공유 서버에 적용하지 않았다면

GitHub 파일 교체 후 아래 절차도 한 번 진행해야 새 직원들의 변경이 저장됩니다.

1. **평소 팀 공유에 연결해 쓰던 브라우저**에서 `https://jsj-sands.github.io/lunch-club/setup.html#update`를 엽니다. 강력 새로고침 후 맨 위에 ‘이번 수정본 · 간단한 일일 현황’이 보이는지 확인합니다.
2. **공유 서버 코드 전체 복사**를 누릅니다. 이 브라우저에 저장된 기존 팀 키가 코드에 들어갑니다. 다른 브라우저라면 ‘다른 브라우저에서 설정했거나 기존 팀 키가 있어요’에서 기존 키를 입력한 후 복사합니다.
3. Google Apps Script의 **기존 ‘SANDS 점심판’ 프로젝트**를 엽니다. 기존 `Code.gs`의 내용을 전체 선택해 복사한 코드로 교체하고 저장합니다. 이미 공유·이미지 연결을 완료했다면 초기 실행은 필요하지 않습니다.
4. **배포 → 배포 관리 → 현재 웹 앱 선택 → 수정(연필) → 버전: 새 버전 → 배포**로 갱신합니다.
5. 기존 점심판을 강력 새로고침합니다. 새 직원에게는 **동료 초대**로 복사한 링크를 전달합니다.

같은 Apps Script 프로젝트·팀 키·기존 배포를 사용하면 공유 주소와 초대 링크, 기존 선택·설정·공용 이미지를 이어서 쓸 수 있습니다. ZIP의 `backend/Code.gs`는 팀 키가 비어 있는 원본이므로 **setup.html 코드 복사 버튼**으로 만든 코드를 Apps Script에 붙여넣으세요.

아직 Google 공유 연결을 하지 않았다면 `setup.html`의 처음 설치 순서를 따르면 됩니다.

## 식단 조회와 공용 이미지

### 메가존

- 출처: https://welplan.pmh.codes/restaurants/welstory/REST007327/메가존산학연센터
- 공개 API: https://welplan.pmh.codes/docs/api
- 인증 없는 공개 MCP API를 브라우저에서 호출하고 날짜·식당·응답 형식을 검증합니다.
- 기본은 선택한 날짜의 점심, 주간 보기는 해당 주 월~금입니다. 주간 날짜를 누르면 그날의 선택으로 이동합니다.
- 아직 공개된 메뉴가 없는 날과 통신/응답 오류를 구분합니다. 이전 날짜의 메뉴를 오늘 메뉴로 사용하지 않습니다.
- 최근에 조회한 같은 날짜의 메뉴는 캐시로 보관합니다. 화면이 열려 있으면 5분마다 갱신을 확인합니다.
- 직접 조회 실패 시 기존 Google 공유 연결의 메뉴 조회를 보조 경로로 사용합니다.
- Welplan 메뉴 이미지는 복제하지 않으며 원문에서 확인합니다. Welplan은 식당 운영사와 별개인 독립 서비스입니다.

### 런치타임

- 카카오 채널: https://pf.kakao.com/_xbbMPn
- 지도: https://naver.me/Fr054Jzy
- 친구 추가 후 프로필의 식단을 저장하거나 캡처해서 ‘식단 이미지 올리기’로 공유합니다. 채널 자동 수집은 하지 않습니다.
- 주간용은 월~일, 하루용은 지정한 하루에 표시합니다. 같은 날 둘 다 있으면 하루용을 우선 표시합니다.
- JPG·PNG·WebP, 원본 최대 15MB. 브라우저에서 크기를 조정한 뒤 1MB 이하의 이미지를 공유합니다.

- 한 슬롯에 새 이미지를 올리면 기존 이미지를 교체합니다. 다른 사람이 먼저 수정했다면 확인 없이 덮어쓰지 않고 다시 확인하도록 안내합니다.
- 팀 공유 연결 전에는 이 브라우저의 최근 이미지 3개만 보관하며, 그 상태를 화면에 표시합니다.

## 공유 방식

기존 Google Apps Script 연결을 사용합니다. 점심 선택은 Script Properties, 식단 이미지 파일은 초기 실행 때 생성하는 전용 비공개 Drive 폴더에 보관합니다. 주기적인 상태 조회에는 이미지 정보만 보내고 실제 이미지 파일은 필요할 때 가져옵니다.

사용자의 공유 서버는 팀 키가 맞는 요청만 처리합니다. 초대 링크를 가진 사람은 멤버 이름을 선택해 기록을 수정할 수 있는 소규모 팀 공유판입니다. 실제 팀 키·팀 키를 포함해 생성한 서버 코드·초대 링크는 공개 저장소에 올리지 마세요. 배포되는 기본 소스에는 실제 팀 키가 없습니다.

공유 기록과 전용 식단 이미지는 최근 90일 기준으로 정리합니다. 서로 다른 멤버가 동시에 수정하는 경우 서버 잠금과 변경별 확인 응답으로 처리합니다. 브라우저의 업로드 전송만으로 저장 성공을 표시하지 않고 서버의 저장 확인을 기다립니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| index.html | 점심판 화면 |
| styles.css | PC·모바일 디자인 |
| app.js | 화면, 공유, 식단·이미지 기능 |
| core.js | 날짜·멤버·참석·투표 규칙 |
| menu-source.js | 공개 메가존 식단 조회와 응답 검증 |
| setup.html | 설치·업데이트 안내와 최신 서버 코드 복사 |
| backend/Code.gs | core.js와 서버 코드를 합친 Apps Script 원본 |
| backend/server.js | Google 공유 서버 원본 |
| setup.template.html | 설치 안내 원본 |
| tests/ | 날짜·멤버·식단·이미지·공유 기능 검증 |
| CHECKS.txt | 검증 결과와 범위 |

코드 빌드나 외부 패키지 설치는 필요 없습니다. Node.js가 있으면 `node --test tests/*.test.cjs`로 검증할 수 있습니다.

실제 GitHub 배포·Google 연결은 사용자의 계정에서 진행합니다. 이번 수정 작업에서는 계정의 서버에 접속하거나 배포하지 않았습니다. 업데이트 뒤 서로 다른 기기에서 이미지 하나를 올리고 다른 기기에 보이는지 최종 확인하세요.
