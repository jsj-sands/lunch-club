일일 현황 확인
- 사람 카드와 주간표를 오늘 점심 현황 하나로 통합, 중복 표시 제거
- 함께 점심 / 대표님과 점심 / 오늘 안 먹음 3그룹에 총 10명 각 1회 표시
- 그룹 인원수와 명단 일치, 팀 가나다순 → 이름 가나다순
- 내 이름 선택은 팀별 optgroup, 기본 일정 설정과 공지·투표자 정렬도 같은 순서
- 이전 날 / 다음 날 / 날짜 직접 선택 / 오늘 복귀 시 한 날짜만 표시
- 다음 날 화살표 연속 2회로 화요일·수요일 이동 확인
- 화요일 기본 함께 5명 / 대표님과 점심 5명 / 불참 0명
- 날짜별 대표님 점심 취소/복원은 해당 날짜에만 저장
- 개인 불참·불참 사유·직접 지정한 대표님 일정은 전체 취소와 구분해 보존
- 내 이름 클릭으로 선택일 참석·불참·기본 복원, 타인 클릭은 상세 조회
- 신원 미선택 시 본인 이름 지정 후 일정 변경 가능
- 공유 POST와 수신 확인에 선택한 날짜 사용
- 저장 중 다른 날짜로 이동해도 원래 날짜에 저장하고 현재 날짜의 식단 이미지 유지
- 아직 조회하지 않은 공유 날짜는 실제 데이터 도착 전 확인 중으로 표시하며 취소 비활성
