런치타임 카카오 프로필 자동 조회
- 첨부 QR은 기존 https://pf.kakao.com/_xbbMPn 채널로 연결됨
- 공개 원문 HTML·익명 홈 JSON과 현재 10월 19일 식단 사진 확인
- 실제 Origin GET은 HTTP 200/CORS 헤더가 있어도 본문 Invalid CORS request여서 직접 브라우저 조회 불가 확인
- 기존 Google 공유 서버를 통해 공개 JSON의 실제 큰 이미지 주소 조회
- 채널 ID, HTTPS 카카오 CDN 이미지 주소, MIME, JSON Content-Type, UTF-8 256KiB 한도 검증
- 카카오 원문 요청에 팀 키·쿠키·직원 정보 전송 없음
- 공개 프로필 조회는 팀 공유 키 검증 후 실행, 이름 선택·날짜 인자 불필요
- 페이지 최초 표시 후 조회, 화면이 보이는 동안 5분마다 갱신, 화면 복귀 시 TTL 확인
- 사진 및 전체 식단 새로고침 버튼, 서버 일반 5분 캐시·강제 최소 1분 간격
- 원문 조회 12초 제한, 원격 요청 중에는 서버 잠금 해제
- 첫 동시 조회가 진행 중이면 오류 대신 대기 표시하고 다음 동기화에 재확인
- 늦게 끝난 요청과 이전 공유 연결의 응답이 새로운 사진을 덮지 않음
- 마지막 성공 사진과 확인 시각을 유지, 서버·브라우저 실패를 최신 성공으로 바꾸지 않음
- 사진 자체의 CDN 로드 실패와 원문 JSON 조회 실패를 따로 처리, 재조회로 복구
- 오늘은 자동 사진, 내일·모레·과거 날짜는 별도 보기 버튼과 날짜 안내
- 확인 시각을 식단 날짜로 추정하지 않음, 식단 날짜는 이미지에서 직접 확인
- 기존 하루·주간 업로드를 보존하고 동료가 올린 식단에서 펼쳐 보기
- 자동 사진이 없거나 오류이면 직접 업로드 이미지를 펼침, 로컬 전용 사진 표기 유지
- 카카오 모듈 누락·미지원 서버·원문 오류가 참석 선택과 저장을 막지 않음
