참석 선택과 현황
- 이름 선택과 함께 먹기 / 따로 먹기 / 안 먹기 버튼을 현황 위에 표시
- 함께 점심 / 대표님과 점심 / 안 먹음 / 미선택 4개 상태 그룹
- 대표님 기본 일정 외에는 평일·주말 모두 미선택으로 시작
- 직접 in을 고른 사람만 초록색 그룹, 함께 먹는 인원과 투표 집계에 포함
- 미선택·대표님 일정·불참·따로 먹기의 기존 투표는 보관하고 집계에서 제외
- 개인 대표님 점심 취소는 본인만 미선택으로 이동
- 전체 취소는 해당 날짜의 자동 기본 일정만 미선택으로 변경
- 개인 참석·불참·사유·직접 정한 대표님 일정·따로 먹기는 전체 취소 후에도 보존
- 연차·반차·외근·출장을 단일 불참 사유로 제공
- 기존 팀명 가나다순 → 이름 가나다순, 날짜 화살표·직접 입력·오늘 복귀 유지
- 공유 날짜가 아직 도착하지 않았을 때 실제 인원 대신 확인 중 표시

따로 먹는 모임
- 초대는 보낸 사람만 separate, 받은 사람의 기존 상태는 유지
- 수신자가 수락한 뒤 둘을 한 모임으로 표시하고 함께 점심 집계에서 제외
- 거절·초대 취소·수락한 모임 나가기·개별 식사 동작
- 나간 본인은 미선택, 상대는 따로 먹기 유지
- pending 초대도 예약으로 취급해 중복 모임·강제 편입 방지
- 본인이 점심 상태를 다시 선택하면 본인의 초대·짝만 정리
- 요청의 멤버·역할·상태·ID 검증, 취소 뒤 늦게 도착한 수락은 오류 처리
- 날짜별 저장, 동시에 온 초대와 중복 전송 처리

과천 음식점
- 사용자 네이버 '지정타 점심' 공유 목록의 공개 응답에서 33곳 확인
- 한식 11 / 중식 3 / 일식 8 / 양식 2 / 분식 5 / 아시안 4
- 이름·원문 업종·주소·장소 ID를 확인하고 중복 없음
- 원문 업종과 상위 분류를 기준으로 앱의 여섯 종류에 대응
- 식당·업종·주소 검색, 종류별 필터, 처음 6곳 및 6곳씩 더보기
- 네이버 장소 링크와 선택한 날짜의 점심 후보 추가 연결
- 이미 추가한 후보는 중복 추가하지 않음
- 목록의 소유자 프로필과 내부 사용자 식별자는 배포 데이터에서 제외
- 가격·영업시간·미확인 대표 메뉴를 생성하지 않음
- 자료 확인일 2026-10-19, 원본 목록의 이후 변경은 자동 동기화하지 않음
