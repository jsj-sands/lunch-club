주간 현황판 확인
- 사람 카드 → 주간 현황판 → 식당 선택 순서
- 총 10명 × 월~금 50개 셀, 이름·팀·날짜·참석 인원 표시
- 디자인팀 천진기·서지우는 화요일 대표님과 점심, 취소 체크 시 함께 점심, 해제 시 기본 복원
- 각 날짜 취소 on/off는 해당 날짜에만 저장하며 현재 선택 날짜와 다른 날짜는 유지
- 개인 불참·불참 사유·직접 지정한 별도 대표님 일정은 전체 취소와 구분해 보존
- 본인 셀의 참석·불참·기본 복원을 클릭한 날짜에 저장
- 다른 사람의 셀은 상세 정보만 표시하고 내 이름·저장값을 변경하지 않음
- 이전 주 / 다음 주 / 이번 주 / 날짜 헤더 이동
- 공유 POST와 서버 확인에 클릭한 날짜 사용
- 토요일을 보면서 화요일 일정을 바꿔도 토요일 공용 식단 이미지 정보 유지

기존 기능 확인
- 10명 명단, 연구기획팀 월·목 / 경영지원팀 수 / 디자인팀 화 / 영업팀 월·금 기본 일정
- 기본 주간 참석 인원 월6 / 화5 / 수7 / 목9 / 금6
- 기존 저장된 요일·만남 시간·적용 기간 유지, 신규 5명 선택·투표·이미지 공유
- 메가존 날짜별·주간 식단, 미등록과 조회 오류 구분
- 이미지 업로드→서버 확인→다른 기기 표시, 주간/하루 범위와 로컬 저장 구분
- 서버 용량·MIME·중복·충돌·실패 복구와 관련 없는 파일 보존

배포 및 화면 소스 확인
- index.html, app.js, styles.css의 주간 현황판 ID·클래스 연결 검토
- 모바일 이름 열 고정, 가로 스크롤, 상태 텍스트 대비, 키보드 포커스 규칙 검토
- 앱·서버·설정 페이지 스크립트 문법 검사 및 생성 서버 코드 동일성 확인
- 직전 10명 버전과 서버 코드가 동일하여 이번 UI 변경만으로는 서버 재배포 불필요
