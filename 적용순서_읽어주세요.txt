강남밥상 Threads 게시물 미표시 오류 수정
버전: 20261020-gas-url-fix

이번 수정은 Google Apps Script에서 지원하지 않는 URL 기능 때문에 정상 게시물을 거부하던 코드 오류를 고칩니다. 실제 공개 피드가 현재 정상 응답하는지, 영상이 재생되는지는 적용 후 확인해야 합니다.

1. 이 ZIP을 압축 해제합니다.
2. GitHub의 jsj-sands/lunch-club 저장소 → Add file → Upload files에서 다음 4개만 기존 위치에 올립니다.
   index.html
   app.js
   threads-menu-source.js
   setup.html
   기존 styles.css, core.js, assets 폴더나 다른 파일을 삭제하지 마세요.
3. Commit changes로 저장합니다. GitHub Pages 반영이 완료되면 기존 팀 공유를 설정했던 브라우저에서 아래 주소를 엽니다.
   https://jsj-sands.github.io/lunch-club/setup.html#update
4. 첫 업데이트 제목이 '이번 수정 · 강남밥상 게시물 미표시 오류 수정'이고, 버전이 20261020-gas-url-fix인지 확인합니다.
   예전 제목이면 페이지를 강력 새로고침한 다음 진행하세요.
5. '공유 서버 코드 전체 복사'를 누릅니다.
6. 기존 메인 Lunch Club Google Apps Script 프로젝트를 엽니다. Code.gs를 복사한 전체 코드로 교체하고 저장합니다.
   별도 동료 계정의 알림 중계 프로젝트가 아니라 기존 메인 점심판 프로젝트입니다.
7. 배포 → 배포 관리 → 기존 웹 앱의 수정(연필) → 버전: 새 버전 → 배포를 누릅니다.
   새 프로젝트나 별도 새 배포 주소를 만들지 마세요.
8. 점심판을 새로고침하고 강남밥상 카드의 'Threads 새 게시물 확인'을 누릅니다.

계속 표시되지 않으면
- 강남밥상 카드의 '조회 진단 보기'를 펼쳐 그 부분을 캡처해 주세요.
- 받은 게시물 수, 선택 날짜에 해당하는 수, 목록의 최신 게시일, 표시 가능한 사진/영상 수, HTTP 상태가 나옵니다.
- 'HTTP_403'이나 'HTTP_429'라면 게시물 없음이 아니라 외부 피드의 접근 제한 응답입니다.
- 최신 게시일이 어제라면 받은 피드 목록이 아직 오늘 게시물을 포함하지 않은 것입니다. 식당이 오늘 게시물을 안 올렸다고 단정할 수는 없습니다.
- 수정 버전이 이전 서버로 표시되면 Google Apps Script의 기존 배포가 새 버전을 사용하도록 갱신됐는지 확인하세요.

유지되는 설정
- 가장 최근에 만든 10명 Google Drive → Slack 알림 중계 코드도 포함했습니다.
- Threads 조회 관련 부분 외의 최신 서버 코드는 원본과 동일한 것을 비교 확인했습니다.
- 기존 직원 이메일, 본인용 중계 URL·비밀키, 팀 키, /exec 주소는 변경하지 마세요.
- 동료 계정의 별도 중계용 Code.gs는 이번 작업에서 바꾸지 않습니다.
- 참석 기록, 초대, 식당 선택, 글씨 크기·섹션 디자인은 유지됩니다.

선택 진단
Apps Script 함수 목록의 testGangnamThreadsConnection을 실행하면 실행 로그에도 진단 내용이 나옵니다. 이 함수는 팀 키·토큰·직원 이메일을 로그에 출력하지 않습니다.
