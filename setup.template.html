코딩은 끝났어요.
이제 우리 점심판을 열어볼까요?

파일을 GitHub에 올리면 화면이 열립니다. 동료와 선택을 공유하려면 Google 연결을 한 번 더 진행해 주세요. 코드 작성 없이 복사·붙여넣기로 설정할 수 있습니다.

이번 수정본 · 대표님 장소 + 다인원 따로 먹기 맛집 등록

일반 점심은 메가존 / 런치타임 중 한 곳만 개인별로 고릅니다. 대표님과 점심인 사람은 과천 맛집 골라보기 → 대표님 점심 장소을 누르면 그날 모든 대표님 점심 참석자가 동일한 식당을 확인할 수 있습니다. 따로 먹기는 동료를 여러 명 한꺼번에 초대하고 모임별로 과천 맛집 식당을 등록할 수 있습니다. 식당 예약은 별도로 진행합니다.

간편식·데일리팩·테이크아웃을 제외하고 메가존 일반식 메뉴 1·메뉴 2만 표시합니다. 오늘과 주간 요약·상세에 모두 적용되며 날짜가 바뀌어도 계속 유지됩니다. 일반식 사진과 반찬 목록은 그대로 볼 수 있습니다.

메가존은 메뉴별 음식 사진과 밥·국·반찬 목록까지 보여 줍니다. 사진을 누르면 확대할 수 있고, 이번 주 식단은 날짜별 사진·반찬 보기를 펼치면 됩니다. 사진이 없는 날에도 메뉴명은 표시됩니다.

동료가 올린 식단에 ‘올린 이미지 삭제’를 추가했습니다. 내 이름을 고른 뒤 버튼을 누르고, 하루·주간의 적용 기간을 확인해 삭제합니다. 공유 이미지는 팀 모두의 화면에 반영되고 카카오 자동 사진은 계속 표시됩니다. 하루용을 삭제한 뒤 기존 주간용이 표시될 수 있습니다.

회사 CI 심벌과 공식 워드마크를 적용했습니다. 사이트 전체의 한글은 Pretendard, 영문·숫자는 Red Hat Display로 표시됩니다. 두 글꼴 파일을 함께 포함했습니다. 배경은 로고 시스템 자료의 미색 #F7F5F0이며 주요 버튼과 강조 요소는 회사 레드입니다. 식당 분류는 스마트경양식 → 양식 / 샤브올데이 → 아시안 / 상월 → 일식으로 보정했습니다.

카카오 프로필 사진을 매일 저장하지 않아도 런치타임 식단을 볼 수 있어요. 공유 서버 연결 후 점심판을 열면 자동으로 가져오고, 화면이 열려 있는 동안 약 5분마다 다시 확인합니다. 사진을 누르면 크게 볼 수 있습니다.

확인 시각은 식단 날짜가 아닙니다. 사진에 적힌 날짜를 확인해 주세요. 내일·모레 화면에는 현재 프로필 사진을 그날 식단으로 표시하지 않습니다. 조회 실패 시 이전 사진·원문 링크·직접 업로드를 사용할 수 있어요.

함께 먹기 · 따로 먹기 · 안 먹기를 화면에서 바로 선택합니다. 함께 점심 / 대표님과 점심 / 오늘 안 먹음 / 미선택 네 그룹과 따로 먹는 모임을 확인할 수 있습니다.

  • 직접 함께 먹기를 선택한 사람만 초록색 그룹에 들어갑니다. 대표님 기본 일정 외에는 미선택으로 시작합니다.
  • 내 대표님 점심 취소 버튼과 대표님 점심 전체 취소 체크를 보이게 배치했습니다. 취소 후에는 미선택으로 이동합니다.
  • 불참 사유에 연차·반차·외근·출장을 하나의 항목으로 추가했습니다.
  • 따로 먹기에서 동료를 초대하고 각 동료가 수락하면 여러 명의 한 모임으로 표시합니다. 모임별 식당도 따로 등록합니다.
  • 런치타임 아래에 주변 식당을 한식·중식·일식·양식·분식·아시안으로 정리했습니다.
  • 한 번에 하루만 표시하고 ← / →로 날짜를 바꿉니다. 팀명과 이름은 가나다순입니다.
중요: 이번 업데이트는 GitHub 파일과 Google Apps Script 공유 서버의 두 곳 모두를 업데이트해야 합니다. 웹 화면만 바꾸면 팀 전체가 공유하는 다인원 따로 먹기와 모임별 식당을 저장할 수 없습니다. 기존에 쓰던 Google Apps Script 프로젝트의 같은 웹 앱 배포를 새 버전으로 갱신해야 기존 참석 기록·식단 이미지를 유지할 수 있습니다.

1. GitHub 파일 교체

  1. 이번 ZIP을 압축 해제합니다. 기존 lunch-club 저장소에서 Add file → Upload files를 누릅니다.
  2. 압축을 푼 폴더 안의 파일과 하위 폴더를 모두 끌어놓고 기존 Pages 배포 브랜치에 Commit changes로 저장합니다. index.html이 저장소 첫 화면에 바로 보이는 위치를 유지합니다. assets 폴더의 로고·폰트와 lunchtime-source.js, restaurant-guide.js도 함께 올립니다.
  3. GitHub Pages 업데이트가 끝나면 다음 단계의 공유 서버 업데이트를 반드시 진행해 주세요.

2. 기존 Google 공유 서버 업데이트 · 이번 변경에 필수

기존 팀 공유를 이용 중이라면 새 프로젝트를 만들지 말고 기존 Google Apps Script 프로젝트의 코드와 현재 웹 앱 버전을 업데이트하세요. 기존 팀 키와 /exec 공유 주소도 그대로 유지합니다.

  1. 평소 팀 공유에 연결해 쓰던 브라우저에서 https://jsj-sands.github.io/lunch-club/setup.html#update를 엽니다. 강력 새로고침 후 위 제목이 ‘이번 수정본 · 대표님 장소 + 다인원 따로 먹기 맛집 등록’인지 확인합니다. Windows: Ctrl+Shift+R / Mac: ⌘+Shift+R.
  2. 아래 공유 서버 코드 전체 복사를 누릅니다. 이 브라우저에 저장된 기존 팀 키가 코드에 들어갑니다. 다른 브라우저라면 ‘다른 브라우저에서 설정했거나 기존 팀 키가 있어요’를 열고 기존 키를 입력한 뒤 복사합니다.
  3. Google Apps Script의 기존 SANDS 점심판 프로젝트를 엽니다. Code.gs 전체를 복사한 새 코드로 교체하고 저장합니다. 이미 공유·이미지 연결을 완료했다면 초기 실행은 필요하지 않습니다.
  4. 배포 → 배포 관리 → 현재 웹 앱 선택 → 수정(연필) → 버전: 새 버전 → 배포로 갱신합니다.
  5. 기존 점심판을 새로고침해 팀 공유 연결됨을 확인합니다. 대표님 점심 참석자 이름으로 과천 맛집을 고른 뒤 우측 대표님 점심 장소에 확정된 식당이 표시되는지 확인해 주세요. 다른 기기에서도 동일한 장소가 표시되어야 합니다. 추가로 3명 이상 따로 먹는 모임을 만들고 모임별 식당이 다른 기기에도 보이는지 확인합니다. 기존 카카오 사진·메가존 사진·반찬도 계속 사용할 수 있습니다.

같은 프로젝트·팀 키·기존 배포를 갱신하면 공유 주소와 초대 링크, 저장된 개인 선택·일정 설정·공용 이미지를 이어서 쓸 수 있습니다. 코드가 들어 있는 ZIP 원본은 팀 키가 비어 있으므로 위 복사 버튼으로 만든 코드를 사용하세요.

이전 화면에서 자동으로 함께 먹는 것으로 보이던 사람은 이제 미선택입니다. 예전에 직접 선택한 참석·불참과 식당 선택 기록은 유지됩니다. 미선택인 사람의 예전 식당 선택은 직접 함께 먹기를 선택한 뒤에만 다시 집계됩니다.

2. 우리 멤버들의 선택 연결하기

Google 계정 하나로 한 번만 연결합니다. 별도 스프레드시트를 직접 만들 필요는 없습니다. 런치타임 식단 이미지를 보관할 비공개 Google Drive 폴더는 초기 실행 시 자동으로 만듭니다.

1

설정 안내를 공개된 주소에서 여세요

GitHub에 올린 뒤 https://jsj-sands.github.io/lunch-club/setup.html을 열어 이 단계를 진행해 주세요. 이 브라우저에 팀 키를 보관합니다.

지금은 다운로드한 파일을 보고 있습니다. GitHub Pages 배포 후 그 주소의 setup.html에서 연결해 주세요.

2

공유 서버 코드를 복사하세요

아래 버튼은 이 점심판만의 무작위 팀 키가 들어간 코드를 복사합니다. 코드 내용을 수정할 필요가 없습니다.

코드 직접 선택해서 복사하기

이 단계에서 복사한 코드와 팀 키는 GitHub에 올리지 마세요. Google Apps Script에만 붙여넣습니다. ZIP에 들어 있는 기본 소스에는 실제 팀 키가 없습니다.

3

Google Apps Script에 붙여넣으세요

Google Apps Script 열기 ↗ → 새 프로젝트를 누릅니다. 프로젝트 이름은 SANDS 점심판으로 바꿔 주세요.

처음 보이는 Code.gs의 내용을 전부 지운 뒤 복사한 코드를 붙여넣고 저장합니다. 코드를 일부분만 붙이지 않도록 주의해 주세요.

4

초기 실행을 한 번 해주세요

상단 실행 함수 목록에서 initializeLunchClub을 선택하고 실행을 누릅니다. 권한 검토 화면이 뜨면 본인이 방금 만든 프로젝트와 계정이 맞는지 확인하고 승인합니다.

이 코드는 점심 선택 저장, 공개 식단 조회, 런치타임 식단 이미지 보관을 사용합니다. Google Drive에 식단 전용 폴더를 만들기 위한 권한이 추가되었습니다. 실행 로그에 점심판 준비 완료가 뜨면 성공입니다.

본인이 만든 앱의 확인 안내가 나와요

직접 만든 미검증 Apps Script에 Google의 경고 화면이 나올 수 있습니다. 프로젝트가 방금 만든 SANDS 점심판인지 확인한 뒤 고급 메뉴의 프로젝트 이동 항목으로 진행하세요. 회사 계정의 관리자가 허용하지 않은 경우에는 관리자에게 허용 가능한 연결 방식을 확인해야 합니다.

공유 서버는 팀 키가 있는 요청만 처리합니다. 초대 링크를 가진 사람은 이름을 선택해 기록을 수정할 수 있는, 우리 팀을 위한 간단한 공유판입니다.

처음 코드를 복사한 브라우저에서는 자동 입력됩니다. 기존 연결의 키를 쓸 때만 변경하세요.

7

동료에게 초대 링크를 보내세요

점심판 상단에 팀 공유 연결됨이 표시되면 동료 초대를 누릅니다. 복사된 링크를 함께 사용할 동료에게 전달하세요. 각자 본인 이름을 선택하면 준비 끝입니다.

선택 결과는 약 30초마다 확인합니다. 팀 공유에 연결하기 전 이 기기에 저장했던 선택은 자동으로 업로드하지 않습니다.

매일은 이렇게 사용해요

  1. 오늘 점심, 어떻게 할까요?에서 나는 → 내 이름을 선택합니다. 팀명과 이름은 가나다순으로 표시됩니다.
  2. 큰 버튼 함께 먹기 · 따로 먹기 · 안 먹기 중에서 선택합니다. 아무것도 선택하지 않으면 미선택입니다. 함께 먹기를 선택해야 초록색 그룹과 식당 투표 집계에 포함됩니다.
  3. 안 먹는 날에는 필요한 경우 사유를 선택합니다. 연차·반차·외근·출장은 하나의 항목입니다.
  4. 자동으로 들어간 대표님 일정이 취소됐다면 내 대표님 점심 취소를 누르고 점심 여부를 다시 고릅니다. 그날 전체 일정이 취소됐을 때에는 대표님 점심 전체 취소를 체크합니다.
  5. 동료끼리 따로 먹는 날은 따로 먹기 → 동료 여러 명 체크 → 초대를 누릅니다. 초대받은 동료가 본인 이름을 선택하고 수락하고 따로 먹기를 누르면 같은 모임으로 표시됩니다. 혼자 먹을 때는 동료 지정 없이 따로 먹기를 선택합니다.
  6. ← / →로 내일·모레 현황과 선택을 확인하고 오늘 버튼으로 돌아옵니다. 선택과 초대는 화면에 표시된 날짜에만 저장됩니다.
  7. 메가존의 오늘 식단 / 이번 주 식단을 비교합니다. 런치타임은 자동으로 가져온 카카오 프로필 사진을 확인합니다. 사진에 적힌 식단 날짜를 확인해 주세요. 필요한 경우 식단 이미지 직접 올리기로 주간용·하루용 이미지를 따로 공유할 수 있습니다.
  8. 일반 점심에 참여하면 응답 패널 또는 메가존/런치타임 식단 카드에서 둘 중 하나를 고릅니다. 바꾸고 싶으면 다른 한 곳을 누르면 됩니다. 각자의 선택이 집계됩니다.
  9. 대표님과 점심인 사람은 아래 과천 맛집 골라보기에서 종류·이름으로 찾아 대표님 점심 장소를 누릅니다. 우측에 팀 전체가 보는 등록 장소가 표시됩니다. 변경하려면 다른 식당을 고르고 확인합니다.
  10. 대표님 점심의 기본 만남 시간은 설정에 있는 시간(기본 12:00)을 사용합니다. 일반 점심에는 따로 전체 장소 확정 단계가 없고 각자 선택으로 끝납니다.
대표님과 점심·안 먹음·미선택·따로 먹기는 함께 먹는 인원과 식당 투표 집계에서 빠집니다. 기존 식당 선택은 보관되며, 다시 함께 먹기를 선택하면 집계에 돌아옵니다. 초대만 보냈을 때는 상대의 점심 상태가 바뀌지 않습니다.

식단과 일정에 대해 알아둘 점

  • 메가존: 공유 연결 전에도 공개된 날짜별 점심 메뉴를 직접 조회합니다. 오늘과 이번 주 월~금 식단을 볼 수 있습니다. 날짜가 맞는 식단만 표시하며, 미등록과 조회 실패를 구분합니다. 메뉴 사진과 상세 내용은 Welplan 원문에서 확인합니다.
  • 런치타임 자동 조회: 공유 서버가 카카오 채널에 공개된 최신 프로필 사진 주소를 가져옵니다. 별도 카카오 로그인이나 친구 추가가 필요하지 않습니다. 점심판을 열 때와 화면이 열려 있는 동안 약 5분마다 확인합니다. 채널에 아직 전날 사진이 있으면 그 사진이 표시되므로 이미지 속 날짜를 확인해 주세요. 페이지를 닫은 상태의 오전 9시 예약 실행은 이번 버전에 포함하지 않습니다. 공개 화면의 데이터 형식이 바뀌면 자동 조회 코드 조정이 필요할 수 있습니다.
  • 직접 올린 식단 이미지 기간: 주간용은 월~일, 하루용은 지정한 날짜에 표시합니다. 같은 날짜에 하루용과 주간용이 모두 있으면 하루용을 우선 표시합니다. 다음 주에는 지난 주 이미지가 표시되지 않습니다.
  • 이미지 공유: 원본 선택은 15MB까지 가능하며 업로드 전 크기를 조정합니다. 이미지는 전용 비공개 Drive 폴더에 저장하고 팀 키로 조회합니다. 이미지 자체를 인터넷 공개 링크로 만들지 않습니다. 공유 연결 전 미리보기는 이 브라우저에만 보관하며 공유 연결 후 다시 올려야 합니다.
  • 대표님과 점심 기본 일정: 경영지원팀 김윤철·오성은·장윤석 수 / 디자인팀 서지우·천진기 화 / 연구기획팀 최민준 월·목 / 영업팀 조현주 월·금 / 전략사업팀 손주리·윤현수 월·화·금 / 커뮤니케이션팀 조성준 화·금. 연구기획팀은 연구소 팀장 일정을 따릅니다. 첨부 공지를 반영해 2026년 12월 31일까지 적용하며, 설정에서 기간과 요일을 바꿀 수 있습니다.
  • 주말·공휴일: 주말도 기본 미선택입니다. 공휴일은 자동 판정하지 않으므로 필요한 경우 대표님 일정을 취소하고 각자 점심 여부를 선택해 주세요.
  • 과천 맛집: 주변 식당 지도의 가게를 2026년 10월 19일 확인해 정리했습니다. 한식·중식·일식·양식·분식·아시안으로 나누고 스마트경양식·샤브올데이·상월은 요청에 맞게 분류를 보정했습니다. 원본 지도에 이후 추가한 장소는 이 파일에 자동 반영되지 않습니다. 맛집 목록은 대표님 점심 장소와 따로 먹는 모임별 식당 등록에 사용합니다. 일반 점심은 계속 메가존/런치타임 중 하나만 선택합니다.
  • 따로 먹는 모임: 동료 여러 명을 동시에 초대하여 모임을 만들고, 참여자는 모임 식당을 등록할 수 있습니다. 대기 중인 초대를 포함해 한 사람은 한 모임에만 들어갈 수 있습니다. 초대를 거절·취소하면 초대한 사람은 따로 먹기로 남고, 수락한 모임에서 나가면 본인만 미선택으로 바뀝니다.
  • 기록 보관: 공유 기록과 전용 식단 이미지는 최근 90일을 기준으로 정리합니다. 이 기기의 점심 기록은 최근 120일, 이미지 미리보기는 최근 3개를 보관합니다.

상황확인할 것
GitHub 주소가 404예요저장소 첫 화면에 index.html이 있는지, Pages가 main / (root)인지 확인합니다.

동료와 선택이 달라요양쪽 모두 ‘팀 공유 연결됨’인지 확인합니다. 일반 주소 대신 ‘동료 초대’로 복사한 링크를 전달하세요.
팀 키 오류예요코드를 복사했던 브라우저에서 다시 연결합니다. 새 코드를 넣었다면 새 버전으로 재배포해야 합니다.
연결 응답이 없어요웹 앱 실행 사용자 ‘나’, 접근 권한 ‘모든 사용자’, 주소 끝 /exec를 확인합니다. Workspace에서 익명 배포가 금지되어 있으면 관리자 확인이 필요합니다.

올린 이미지 삭제에서 업데이트 안내가 떠요위 안내대로 기존 Code.gs를 교체하고 배포 관리에서 새 버전으로 갱신합니다. 이미 이미지 공유를 쓰고 있다면 초기 실행을 다시 할 필요는 없습니다.
