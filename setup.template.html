이제 우리 점심판을 열어볼까요?

파일을 GitHub에 올리면 화면이 열립니다. 동료와 선택을 공유하려면 Google 연결을 한 번 더 진행해 주세요. 코드 작성 없이 복사·붙여넣기로 설정할 수 있습니다.

이번 수정본 · 주간 현황판

오늘 함께 먹는 사람 → 이번 주, 함께할 점심 → 오늘은 어디로 갈까요? 순서로 바꾸고, 10명의 주간 일정을 확인·변경할 수 있게 했습니다.

  • 월~금의 함께 점심·대표님과 점심·개인 일정을 구분하고 날짜별 참석 인원을 표시합니다.
  • 각 날짜의 대표님과 점심 → 취소를 체크하면 그날의 기본 대표님 점심 참석자가 함께 먹는 상태로 바뀝니다. 체크를 해제하면 기본 일정으로 돌아갑니다.
  • 개인 불참과 직접 바꾼 별도 대표님 일정은 유지됩니다. 본인 칸을 누르면 그 날짜의 참석·불참·사유를 정할 수 있습니다.
  • 다른 사람의 칸은 일정 상세로 열립니다. 날짜 제목을 누르면 그날의 식단·투표로 이동합니다.
  • 이전 주·다음 주를 살펴보고 모바일에서는 이름 열을 고정한 채 가로로 넘길 수 있습니다.
직전 10명 수정본의 공유 서버까지 적용했다면 이번에는 GitHub 파일만 교체하면 됩니다. 기존 공유 주소와 서버 기능을 그대로 사용합니다.

1. GitHub 파일 교체

  1. 이번 ZIP을 압축 해제합니다. 기존 lunch-club 저장소에서 Add file → Upload files를 누릅니다.
  2. 압축을 푼 폴더 안의 파일과 하위 폴더를 모두 끌어놓고 Commit changes로 저장합니다. index.html이 저장소 첫 화면에 바로 보이는 위치를 유지합니다.
  3. GitHub Pages 업데이트 후 점심판을 강력 새로고침합니다. Windows: Ctrl+Shift+R / Mac: ⌘+Shift+R.
  4. 주간표가 사람 카드 아래에 보이는지 확인합니다. 날짜별 참석을 바꾸고 다른 직원 화면에도 반영되는지 확인합니다.

2. 아직 10명 명단을 공유 서버에 적용하지 않았다면

  1. 평소 팀 공유에 연결해 쓰던 브라우저에서 공개된 setup.html#update를 엽니다. 강력 새로고침 후 ‘이번 수정본 · 주간 현황판’이 보이는지 확인합니다.
  2. 아래 공유 서버 코드 전체 복사를 누릅니다. 기존 팀 키가 자동으로 들어갑니다. 다른 브라우저라면 아래 ‘다른 브라우저에서 설정했거나 기존 팀 키가 있어요’에 기존 키를 입력한 후 복사합니다.
  3. 기존 SANDS 점심판 Apps Script 프로젝트의 Code.gs 전체를 새 코드로 교체하고 저장합니다. 이미 공유·이미지 연결을 마쳤다면 초기 실행은 필요하지 않습니다.
  4. 배포 → 배포 관리 → 현재 웹 앱 선택 → 수정(연필) → 버전: 새 버전 → 배포로 갱신합니다.
  5. 기존 점심판을 강력 새로고침합니다. 새 직원에게는 동료 초대로 복사한 링크를 전달합니다.

같은 프로젝트·팀 키·기존 배포를 사용하면 공유 주소와 초대 링크, 기존 선택·설정·공용 이미지를 이어서 쓸 수 있습니다. 총 10명이며 연구기획팀 최민준은 월·목요일, 디자인팀 천진기·서지우는 화요일이 대표님과 점심 기본 일정입니다.

2. 우리 멤버들의 선택 연결하기

Google 계정 하나로 한 번만 연결합니다. 별도 스프레드시트를 직접 만들 필요는 없습니다. 런치타임 식단 이미지를 보관할 비공개 Google Drive 폴더는 초기 실행 시 자동으로 만듭니다.

1

GitHub에 올린 뒤 https://jsj-sands.github.io/lunch-club/setup.html을 열어 이 단계를 진행해 주세요. 이 브라우저에 팀 키를 보관합니다.

지금은 다운로드한 파일을 보고 있습니다. GitHub Pages 배포 후 그 주소의 setup.html에서 연결해 주세요.

2

공유 서버 코드를 복사하세요

아래 버튼은 이 점심판만의 무작위 팀 키가 들어간 코드를 복사합니다. 코드 내용을 수정할 필요가 없습니다.

코드 직접 선택해서 복사하기

이 단계에서 복사한 코드와 팀 키는 GitHub에 올리지 마세요. Google Apps Script에만 붙여넣습니다. ZIP에 들어 있는 기본 소스에는 실제 팀 키가 없습니다.

3

Google Apps Script에 붙여넣으세요

Google Apps Script 열기 ↗ → 새 프로젝트를 누릅니다. 프로젝트 이름은 SANDS 점심판으로 바꿔 주세요.

처음 보이는 Code.gs의 내용을 전부 지운 뒤 복사한 코드를 붙여넣고 저장합니다. 코드를 일부분만 붙이지 않도록 주의해 주세요.

4

초기 실행을 한 번 해주세요

상단 실행 함수 목록에서 initializeLunchClub을 선택하고 실행을 누릅니다. 권한 검토 화면이 뜨면 본인이 방금 만든 프로젝트와 계정이 맞는지 확인하고 승인합니다.

이 코드는 점심 선택 저장, 공개 식단 조회, 런치타임 식단 이미지 보관을 사용합니다. Google Drive에 식단 전용 폴더를 만들기 위한 권한이 추가되었습니다. 실행 로그에 점심판 준비 완료가 뜨면 성공입니다.

본인이 만든 앱의 확인 안내가 나와요

직접 만든 미검증 Apps Script에 Google의 경고 화면이 나올 수 있습니다. 프로젝트가 방금 만든 SANDS 점심판인지 확인한 뒤 고급 메뉴의 프로젝트 이동 항목으로 진행하세요. 회사 계정의 관리자가 허용하지 않은 경우에는 관리자에게 허용 가능한 연결 방식을 확인해야 합니다.

공유 서버는 팀 키가 있는 요청만 처리합니다. 초대 링크를 가진 사람은 이름을 선택해 기록을 수정할 수 있는, 우리 팀을 위한 간단한 공유판입니다.

6

주소를 붙여넣고 연결하세요

다른 브라우저에서 설정했거나 기존 팀 키가 있어요

처음 코드를 복사한 브라우저에서는 자동 입력됩니다. 기존 연결의 키를 쓸 때만 변경하세요.

7

동료에게 초대 링크를 보내세요

점심판 상단에 팀 공유 연결됨이 표시되면 동료 초대를 누릅니다. 복사된 링크를 함께 사용할 동료에게 전달하세요. 각자 본인 이름을 선택하면 준비 끝입니다.

선택 결과는 약 30초마다 확인합니다. 팀 공유에 연결하기 전 이 기기에 저장했던 선택은 자동으로 업로드하지 않습니다.

매일은 이렇게 사용해요

  1. 상단에서 내 이름을 고릅니다. 다음에는 기억합니다.
  2. 사람 카드 아래 주간 현황판에서 모든 멤버의 월~금 일정을 확인합니다. 내 날짜 칸을 누르면 해당 날짜의 참석·불참을 미리 바꿀 수 있습니다.
  3. 안 먹는 날은 내 카드의 일정 변경 → 오늘 점심 안 먹어요를 선택합니다. 속이 안 좋음·선약·병원 등 사유는 선택사항입니다.
  4. 대표님과 점심이 취소됐다면 주간표의 해당 날짜에서 취소를 체크합니다. 그날의 기본 대표님 일정만 풀리며 개인 불참과 직접 바꾼 일정은 유지됩니다.
  5. 메가존 카드에서 오늘 식단 / 이번 주 식단을 눌러 비교합니다. 런치타임은 카카오 채널을 열어 프로필의 식단을 확인합니다.
  6. 런치타임의 식단 이미지 올리기에서 주간용 또는 하루용을 고르고 이미지를 올립니다. 팀 공유 연결 후 올리면 동료들도 같은 이미지를 봅니다. 이미지를 누르면 크게 열립니다.
  7. 함께 정한 식당과 만날 시간을 선택해 오늘 점심 확정하기를 누릅니다.
개인 불참과 대표님과 점심 취소는 해당 날짜에만 적용됩니다. 이미 골랐던 식당은 불참 중 집계에서 빠지고, 다시 함께 먹는 상태가 되면 집계에 돌아옵니다.

식단과 일정에 대해 알아둘 점

  • 메가존: 공유 연결 전에도 공개된 날짜별 점심 메뉴를 직접 조회합니다. 오늘과 이번 주 월~금 식단을 볼 수 있습니다. 날짜가 맞는 식단만 표시하며, 미등록과 조회 실패를 구분합니다. 메뉴 사진과 상세 내용은 Welplan 원문에서 확인합니다.
  • 런치타임: 카카오 채널 친구 추가 후 프로필에 올라온 식단을 확인합니다. 저장하거나 캡처한 JPG·PNG·WebP 이미지를 한 명이 올리면, 같은 팀 공유 연결을 사용하는 동료들에게 표시됩니다.
  • 식단 이미지 기간: 주간용은 월~일, 하루용은 지정한 날짜에 표시합니다. 같은 날짜에 하루용과 주간용이 모두 있으면 하루용을 우선 표시합니다. 다음 주에는 지난 주 이미지가 표시되지 않습니다.
  • 이미지 공유: 원본 선택은 15MB까지 가능하며 업로드 전 크기를 조정합니다. 이미지는 전용 비공개 Drive 폴더에 저장하고 팀 키로 조회합니다. 이미지 자체를 인터넷 공개 링크로 만들지 않습니다. 공유 연결 전 미리보기는 이 브라우저에만 보관하며 공유 연결 후 다시 올려야 합니다.
  • 대표님과 점심 기본 일정: 조성준 화·금 / 손주리·윤현수 월·화·금 / 김윤철·오성은·장윤석 수 / 천진기·서지우 화 / 조현주 월·금. 최민준(연구기획팀)은 연구소 팀장 일정에 따라 월·목요일입니다. 첨부 공지를 반영해 2026년 12월 31일까지 적용하며, 설정에서 기간과 요일을 바꿀 수 있습니다.
  • 주말·공휴일: 주말은 기본 불참입니다. 공휴일은 자동 판정하지 않으므로 개인별 상태를 바꿔 주세요.
  • 기록 보관: 공유 기록과 전용 식단 이미지는 최근 90일을 기준으로 정리합니다. 이 기기의 점심 기록은 최근 120일, 이미지 미리보기는 최근 3개를 보관합니다.

잘 안 될 때

상황확인할 것
GitHub 주소가 404예요저장소 첫 화면에 index.html이 있는지, Pages가 main / (root)인지 확인합니다.
동료와 선택이 달라요양쪽 모두 ‘팀 공유 연결됨’인지 확인합니다. 일반 주소 대신 ‘동료 초대’로 복사한 링크를 전달하세요.
팀 키 오류예요코드를 복사했던 브라우저에서 다시 연결합니다. 새 코드를 넣었다면 새 버전으로 재배포해야 합니다.

식단이 안 떠요원문 서비스 또는 네트워크 문제일 수 있습니다. 카드의 ‘실시간 식단’ / 채널 원문을 확인합니다. 이전 날짜 메뉴를 오늘 것으로 표시하지 않습니다.
이미지를 올릴 수 없어요이번 버전의 서버 코드를 넣고 initializeLunchClub을 다시 실행해 Drive 권한을 허용했는지 확인하세요. 새 버전 배포까지 해야 반영됩니다.
