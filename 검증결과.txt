검증 기록 · 20261020-gas-url-fix

1. 기존 오류 재현
   동일한 정상 영상 게시물 fixture에 대해 브라우저/Node의 URL 생성자가 있는 경우 ok=true.
   URL 생성자가 없는 Google Apps Script 유사 환경에서는 기존 코드가 media=false, post=false, reason=not_found를 반환.
   Google 공식 문서에서도 Apps Script V8의 URL/URLSearchParams 미지원 확인.
   https://developers.google.com/apps-script/guides/v8-runtime#unavailable_apis

2. 수정 검증
   URL 생성자를 사용하지 않는 제한된 HTTPS 주소 검사로 교체.
   URL 없는 환경에서 생성된 Code.gs와 Threads RSS parser를 실행하여 정상 게시물 반환 확인.
   날짜·도메인·위조 호스트·인증정보 포함 URL·캐시 버전·진단 결과 구분 검사 포함.
   전체 자동 테스트: 168개 통과, 0개 실패.
   실행 명령: node --test tests/*.test.cjs

3. 기존 기능 보존
   SANDS_Lunch_Club_10People_Drive_Slack_Relay_20261020.zip의 최신 메인 Code.gs에 병합.
   Threads module, Threads 조회/진단 함수, Threads 캐시 이름을 제외한 코드는 원본과 완전히 동일함을 비교 검증.
   기존 9명 직접 Drive 공유, 본인 중계 Drive 공유, Drive 등록자의 Slackbot 임의 전환 금지 테스트 통과.
   이전 Slackbot 우선 정책을 가정한 테스트 3개는 최신 10명 Drive 정책의 기대값으로 갱신.
   DOM mock의 classList.contains 누락을 실제 브라우저 API와 동일하게 보완.

4. 화면 검사
   Chromium 오프라인 브라우저에서 390px/1280px 화면으로 4가지 상태 검사(총 8회).
   피드 오류, 어제 게시물만 반환, 영상 주소 누락, 구버전 서버 상태.
   8회 모두 JavaScript page error 0건, 가로 넘침 없음.
   외부 응답을 모의한 검사이며 실제 Threads 영상 재생 검사로 해석하면 안 됨.

5. 미확인 사항
   이 환경에서는 운영 사이트 및 RSSHub에 대한 실제 HTTP 응답을 가져오지 못함.
   이 결과만으로 실제 RSSHub가 다운됐거나 403/429를 반환했다고 판단하지 않음.
   사용자 Google Apps Script에서의 실제 피드 조회, 실제 메뉴 영상 재생, 실제 Slack 수신은 별도 확인 필요.
   이번 파일은 코드 오류 수정본이며 자동 수집 성공을 보장하는 완성 확인서가 아님.
